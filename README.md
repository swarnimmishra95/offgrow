# Offgrow

Grow what you don't scroll. Offgrow gives you a cottage garden that blooms on days you stay off social apps and wilts when you doomscroll.

- Android app (Kotlin, Jetpack Compose), with home-screen widgets.
- Screen-time totals are read on the phone with Android's usage access. Nothing leaves the device.
- The garden is drawn by `app/src/main/assets/garden/garden.js` and is unique to each install.

## Getting a build

Every push to `main` builds the app on GitHub Actions. The APK is attached to the **latest** release and to the workflow run.
